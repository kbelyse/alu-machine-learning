# ALU Machine Learning

Machine learning coursework and projects from the Software Engineering program at the African Leadership University.

## Contents

- `math` — linear algebra, calculus, probability, and other math foundations
- `supervised_learning` — classification, RNNs, attention, optimization, regularization, and more
- `unsupervised_learning` — clustering, autoencoders, dimensionality reduction, reinforcement learning
- `pipeline` — data handling with pandas, databases, APIs, and data augmentation

## About

Each folder contains self-contained exercises with their own README explaining the task and approach.
